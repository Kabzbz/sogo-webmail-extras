# Доработки веб-почты SOGo

Один файл `custom-sogo.js` для SOGo из состава
[mailcow-dockerized](https://github.com/mailcow/mailcow-dockerized): веб-почта
становится ближе к привычным почтовым службам, при этом сам SOGo не правится.

Всё живёт в файле, который mailcow и так подключает, поэтому доработки
переживают `update.sh` и пересоздание контейнеров. Ни форков, ни пересборки
образов, ни правки шаблонов в томе — том контейнер переписывает при запуске.

> Проверено на mailcow `2026-09a`, SOGo 5.12.11.

## Что появляется

**Значки отправителей.** Вместо «монстров» Gravatar — настоящие логотипы фирм
(их один раз скачивает вспомогательный скрипт и вшивает прямо в файл),
фотографии людей из Gravatar и Mail.ru, а сотрудникам фирм рисуются инициалы
со значком фирмы в углу. При чтении почты наружу не уходит ни одного запроса.

**Значки папок.** Подбираются по названию: чеки, рассылки, заказы, учёба,
такси и так далее — вместо сорока одинаковых папок. Правила по ключевым
словам, поэтому новая папка получает значок сама.

**Свой порядок папок.** В SOGo папки идут по алфавиту и переставить их нельзя.
В меню ящика появляется пункт «Настроить порядок»: окно со всем деревом,
перетаскивание мышью, порядок хранится в браузере.

**Тянущиеся колонки.** Границы панели папок и списка писем тянутся мышью,
двойной щелчок по разделителю возвращает ширину по умолчанию.

**Окно письма в трёх положениях.** Кнопка на панели перебирает: справа, снизу,
убрано. С убранным окном письмо открывается двойным щелчком в отдельном окне,
причём размером по вашему экрану, а не зашитыми в SOGo 680×520.

**Список писем в одну строку.** Отправитель, тема и дата в ряд, под ними серым
начало письма — как в mail.ru. Под каждой строкой тонкая линия.

**Счётчики непрочитанных везде.** SOGo считает только «Входящие» и открытые
папки; здесь счётчики запрашиваются по всем, у свёрнутой папки показывается
итог по вложенным, а рядом с числом писем стоит число непрочитанных — щелчок
по нему оставляет в списке только их.

**Починка кодировок.** Лечит кракозябры: UTF-8, прочитанный как Latin-1
(`Ð°Ñ€Ñ…Ð¸Ð²` → `архив`), текст в windows-1251 и темы, где отправитель разрезал
букву между двумя кусками заголовка (SOGo показывает мусор, Mail.ru — нет;
теперь и мы нет). Немецкий и французский текст не трогается.

**Оформление панелей.** Переход цвета на верхней панели и шапке папок, узор
вшит в стиль как SVG — ничего не грузится со стороны.

## Установка

```bash
cd /opt/mailcow-dockerized
cp custom-sogo.js data/conf/sogo/custom-sogo.js
docker compose restart sogo-mailcow
```

Больше ничего не нужно: mailcow сам монтирует этот файл в контейнер, а
`sogo.conf` уже перечисляет его в `SOGoUIAdditionalJSFiles`.

Две настройки SOGo стоит добавить в `data/conf/sogo/sogo.conf` (после правки
перезапустить SOGo):

```
/* Счётчики непрочитанных по всем папкам, а не только по открытым.
   Записывать ЧИСЛОМ: код сравнивает строго. */
SOGoMailFetchAllUnseenCountFolders = 1;
SOGoRefreshViewCheck = every_5_minutes;

/* Через сколько секунд показанное письмо помечается прочитанным.
   0 — сразу, -1 — никогда. */
SOGoMailAutoMarkAsReadDelay = 5;
```

### Значки отправителей (по желанию)

`sender-logos.py` работает на хосте mailcow: читает заголовки «От кого» через
`doveadm`, скачивает логотип на домен и фотографию на адрес, уменьшает их и
вписывает в `custom-sogo.js` между метками `SENDER-LOGOS`.

```bash
apt install python3-pil fonts-dejavu-core
install -m 755 sender-logos.py /usr/local/sbin/
cp systemd/sender-logos.* /etc/systemd/system/
systemctl enable --now sender-logos.timer
```

В начале скрипта укажите свои домены в `OWN`. Уже полученное повторно не
качается: неудачи повторяются через 90 дней, найденное обновляется тоже раз в
90 дней.

**Готовый файл публиковать нельзя.** Во вшитом блоке лежат домены и адреса
всех, кто вам пишет.

## Что стоит знать, прежде чем править

Всё это стоило дня работы и записано ещё и в комментариях к коду.

- **`md-button`, `md-subheader` и подобные — директивы с заменой элемента.**
  В готовой странице это `<button>` и `<div class="md-subheader">`, поиск по
  имени тега не находит ничего.
- **Отладочная информация Angular отключена** (`debugInfoEnabled(false)`),
  поэтому `angular.element(el).scope()` пуст. А `.controller('sgMessageListItem')`
  работает и отдаёт само письмо.
- **Список писем — виртуальный, с жёсткой высотой строки** (`md-item-size="56"`,
  у папок `40`). Если стиль сделает строку ниже, внизу останется пустота — и
  это не сбой отрисовки.
- **Свёртывание колонок считается в долях ширины экрана**: `-20vw` у панели
  папок, `-37.5vw` у списка. Сузите колонку — и раскладку утянет влево. Здесь
  обе величины заменены измеренной шириной.
- **`window.opener` не признак отдельного окна.** У обычной вкладки, открытой
  из соседней, он тоже есть. Отдельное окно письма узнаётся по `UIxMailPopupView`
  в адресе.
- **Запрос `viewplain` помечает письмо прочитанным** — IMAP ставит `\Seen` при
  чтении тела. Поэтому сразу после чтения текста метка возвращается запросом
  `markMessageUnread`. Доли секунды письмо всё же числится прочитанным, и если
  второй запрос потеряется, оно таким и останется.
- **Браузеру отдаётся копия** `custom-sogo.js` из тома `sogo-web-vol-1`,
  которую контейнер делает при запуске. Правка исходника без копирования
  выглядит как «код не работает».

## Снимки экрана

![Список писем и панель папок](docs/list.png)

Строки в один ряд с серым отрывком текста, значки папок по названию,
счётчики непрочитанных у каждой папки и итог рядом с числом писем
(`319 сообщения / 66` — щелчок по второму числу оставляет только непрочитанные).

![Окно письма снизу](docs/panes.png)

Та же кнопка на панели перебирает положение окна письма: справа, снизу,
убрано. Разделитель следует за положением — вертикальный справа,
горизонтальный снизу, — и размер запоминается отдельно для каждого.
